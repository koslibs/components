# Button

## 1.1.0

- Подпись кнопки использует общий `--font-primary` из темы библиотеки.
  Inter подключается автоматически; семейство шрифта можно переопределить
  в CSS приложения или контейнера.

## 1.0.0

- Перенесён Button из core-components GullEye: шесть вариантов оформления,
  размеры 32–72, две формы, аддоны, подпись, block, disabled и loading.
- Сохранены блокировка нажатий во время загрузки, минимальное время отображения
  спиннера 500 мс, ref и стандартные HTML-атрибуты кнопки.
- Доступны публичные `Button` и `ButtonProps` через `@koslibs/components/Button`.
- Стили и публичный компонент Spinner подключаются вместе с Button. Для размеров,
  скруглений и шрифтов добавлены CSS fallback-значения; глобальные стили GullEye
  не требуются.
- Перенесены Docs и Playground в Storybook.
- Docs разделены на вкладки с документацией, импортом, Props, CSS-переменными и
  историей изменений компонента.
