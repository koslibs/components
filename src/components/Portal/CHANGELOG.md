# Portal

## 1.4.0

- Добавлен Portal с импортом `@koslibs/components/Portal`.
- Содержимое переносится в body или контейнер из getPortalContainer без обёртки.
  null и undefined скрывают содержимое; ref указывает на контейнер.
- По умолчанию immediateMount=true: содержимое сразу монтируется в существующий
  контейнер. immediateMount=false откладывает монтирование, чтобы дождаться
  DOM-контейнера из ref.
- При смене контейнера содержимое переносится в новый; при размонтировании
  удаляются только дочерние элементы Portal.
- Добавлены Docs и Playground. CSS, шрифты и оформление не подключаются.
