# Sidepanel

## 1.15.0

- Добавлен публичный onExited?: VoidFunction — уведомление после анимации ухода и фактического закрытия dialog. onClose сохраняет назначение запроса закрытия.
- При reduced motion onExited вызывается сразу после закрытия. Повторное открытие отменяет прежнее завершение; начальное open=false, ререндер и принудительное размонтирование не вызывают callback.
- Добавлены тесты жизненного цикла, включая StrictMode, и пример удаления экземпляра менеджером через onExited в Storybook.

## 1.14.2

- Footer принимает готовые JSX-элементы кнопок в primary и secondary вместо ComponentType. Пропсы, обработчики и ref переданных кнопок сохраняются; primary остаётся обязательным.
- Обновлены примеры Storybook и проверки JSX-контракта; gap, layout и sticky сохраняют прежнее поведение.

## 1.13.0

### Добавлено

- Панель шириной 500 px с плавным выездом и уходом вправо за 200 мс; на узком экране занимает всю ширину.
- Header с необязательным title и hasCloser, прокручиваемый Content и Footer только для Button.
- Footer принимает компоненты ComponentType<ButtonProps>: обязательный primary справа и необязательный secondary слева; внешний вид кнопок задаётся снаружи.
- Footer.gap: 12/16/24/32, по умолчанию 12; layout: start/end/center/space-between/column, по умолчанию space-between.
- Header без заголовка и крестика не выводится и не занимает места.
- Footer.sticky по умолчанию true; при false кнопки прокручиваются вместе с содержимым, Header остаётся видимым.
- Режим прокрутки Footer переключается классом CSS Module; служебный data-sidepanel-footer-sticky удалён.
- Тонкий скруглённый слайдер скроллбара без стрелок и фона в обоих режимах Footer.
- Обычные кнопки справа, две block-кнопки на всю ширину в один ряд и раскладка column в два ряда.
- Бекдроп Modal: чёрный 70%, blur 2 px, без дивайдеров между областями панели.
- Управляемые open/onClose, закрытие по Escape, бекдропу и крестику, блокировка прокрутки до конца анимации.
- Нативный dialog с удержанием и возвратом фокуса, Portal и общий с Modal счётчик блокировок прокрутки в src/utils/lock-scroll.ts.
- Панель закрывает всю ширину до края окна и при scrollbar-gutter: stable / stable both-edges; положение содержимого страницы сохраняется.
- Отмена закрытия при повторном открытии, размонтирование после анимации и поддержка prefers-reduced-motion.
- Отдельный импорт, публичные типы и ref, Storybook Docs/Playground, тесты поведения и сборки импортов.
