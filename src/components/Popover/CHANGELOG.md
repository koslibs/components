# Popover

## 1.4.0

- Используется общий компонент Portal. По умолчанию содержимое по-прежнему
  монтируется сразу в body документа anchorElement; getPortalContainer выбирает
  другой контейнер. Сохранена поддержка Popover внутри нативного dialog.

## 1.2.0

### Добавлено

- Перенесён управляемый Popover из core-components GullEye.
- Публичные экспорты `Popover`, `PopoverProps` и `PopoverPosition` через
  `@koslibs/components/Popover`.
- Сохранены позиционирование, автоматическая смена стороны, ширина якоря,
  ограничение размеров и закрытие по Escape или нажатию снаружи.
- Offset по умолчанию равен `[0, 0]`: содержимое открывается без смещения и зазора.
- Портал по умолчанию использует body документа anchorElement; другой контейнер
  задаётся через getPortalContainer.
- Поддерживаются React 18 и 19: движок Popper подключён напрямую без react-popper.
- Содержимое рендерится напрямую, без внутренней оформленной обёртки.
  Фон, цвет, рамка, скругление, отступы, шрифт и прокрутка задаются снаружи.
- Тень принадлежит Popover: --popover-shadow по умолчанию равен
  `0 8px 24px rgba(0, 0, 0, 0.16)`.
- Popover не подключает шрифты. Доступны CSS-переменные z-index, доступной высоты
  и отступа от границ экрана, а также тени; свойства colors и contentClassName отсутствуют.
- Добавлены Docs с вкладками документации, Props, CSS-переменных и истории,
  а также Playground и примеры из GullEye. Их прежнее оформление сохранено
  в содержимом примеров и не включается в npm-сборку Popover.
