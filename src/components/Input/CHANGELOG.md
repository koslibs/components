# Input

## 1.5.0

- В примерах используется SearchIcon из @koslibs/icons вместо локального SVG.
- Убраны служебные ID сообщений и счётчика, автоматические aria-describedby и aria-invalid.
- Счётчик длины уменьшен до 11 px и выровнен с label по базовой линии текста.
- Добавлен showValueLength: счётчик длины при заданном maxLength, внутри поля
  для inner и рядом с внешним label для outer. Обновляется при вводе, очистке и сбросе.
- Сообщение ошибки заменяет hint; без hint отображается только красная рамка.
- Размер по умолчанию — 40.
- Исправлен фокус при клике по полю внутри контейнеров с tabIndex;
  интерактивные аддоны сохраняют собственный фокус.
- Внутренний label поднимается при фокусе и заполнении; placeholder пустого поля
  появляется только при фокусе. После blur пустого поля label возвращается в центр.

- Добавлен Input по дизайну Figma: primary и secondary, размеры 40/48/56/64/72,
  внешний и внутренний label, hint/error, аддоны и очистка.
- Поддержаны управляемый и неуправляемый ввод, ref нативного input, HTML-атрибуты,
  disabled/readOnly и восстановление defaultValue при сбросе формы.
- Клик по label переводит фокус в input; очистка возвращает фокус после нажатия.
- Добавлены отдельный импорт, Docs/Playground, CSS-переменные и проверки поведения.
