# Space

## 1.9.0

### Добавлено

- Горизонтальная и вертикальная flex-раскладка с отступами из глобальных --size-\*.
- Обязательные size и children. size принимает одно положительное число из шкалы --size-\*, без значения по умолчанию; align, wrap и fullWidth.
- Прямые дочерние элементы, ref, нативные атрибуты div и импорт @koslibs/components/Space.
- Storybook Docs и Playground.
