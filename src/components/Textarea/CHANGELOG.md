# Textarea

## 1.7.0

- Подпись, подсказка и счётчик используют автоматическую высоту строки Typography
  без локальных переопределений.

## 1.6.0

- Добавлено многострочное поле по дизайну Figma с primary/secondary, inner/outer label,
  Typography, подсказкой и ошибкой на её месте.
- Добавлены minRows/maxRows, autosize, вертикальный resize, maxLength,
  showValueLength, очистка, управляемый и неуправляемый режимы.
- Сохранены нативные ref, атрибуты и поведение формы, добавлены Docs и Playground.
- Внутренний скроллбар отображается без стрелок и фона, с тонким закруглённым ползунком.
