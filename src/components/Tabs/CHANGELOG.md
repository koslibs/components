# Tabs

## 1.13.0

- У disabled-вкладок и их счётчиков установлен курсор `not-allowed` вместо `default`.

## 1.7.0

- Заголовки и счётчики используют TypographyText с размерами 14 и 11 px.
- Добавлены вкладки по документации Figma: размеры 40/48, счётчик, hover с серым
  индикатором, selected с оранжевым индикатором и disabled.
- Добавлен составной API: Tabs с дочерними Tab, selectedId/defaultSelectedId,
  onChange(event, { selectedId }), title, count и disabled. Содержимое выбранной вкладки
  отображается отдельными компонентами приложения.
- Добавлены controlled/uncontrolled и выбор соседней доступной
  вкладки при изменении children.
- Добавлены Docs и Playground с примерами внешнего содержимого.
- Во вкладке «Разработчику» показаны props обоих компонентов: Tabs и Tab.
- Tab отображает кнопку вкладки и её состояния; Tabs управляет общим выбором,
  индикатором через внутренний контекст.
- Ряд вкладок должен помещаться в доступную ширину; горизонтальная прокрутка
  и перенос ряда не поддерживаются.
- Активный индикатор плавно перемещается между вкладками и меняет ширину за 200 мс.
  Положение обновляется при изменении размеров вкладок; начальное отображение без анимации.
