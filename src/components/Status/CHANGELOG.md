# Status

## 1.8.0

### Добавлено

- Плашка статуса по финальной документации Figma: размеры 20/24/32/40, формы
  rectangular/rounded и восемь цветов, включая sand.
- Независимые декоративные leftAddon/rightAddon, подпись через обязательный message,
  ref и атрибуты span. При ограничении ширины подпись сокращается многоточием.
- Docs и Playground с размерами, цветами, аддонами и примером обновления статуса.
- Импорты из @koslibs/components и @koslibs/components/Status.
- uppercase (по умолчанию false) отображает подпись заглавными буквами через TypographyText.
