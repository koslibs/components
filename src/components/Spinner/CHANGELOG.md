# Spinner

## 1.0.0

- Перенесён Spinner из core-components GullEye как отдельный публичный компонент.
- Доступны `Spinner` и `SpinnerProps` через `@koslibs/components/Spinner`.
- Сохранены размеры 16, 24 и 48, управление видимостью, настройка цвета через
  `style.color`, CSS-класс, id и dataTestId.
- Каждый экземпляр использует уникальный id SVG-маски через React useId.
- CSS Modules подключаются автоматически; отступы имеют значения по умолчанию
  без глобальных стилей GullEye.
- Добавлены Docs и Playground в Storybook. Button использует этот же компонент
  для отображения загрузки.
- Docs разделены на вкладки с документацией, импортом, Props, CSS-переменными и
  историей изменений компонента.
