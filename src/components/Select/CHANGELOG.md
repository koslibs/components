# Select

## 1.9.0

### Добавлено

- Одиночный и множественный выбор по id: `options`, `value`/`defaultValue`, `onChange`.
- Локальный поиск с внутренним состоянием запроса, управляемое раскрытие, сообщение при отсутствии совпадений.
- Значения через запятую, однострочное многоточие, размеры 40–72, primary/secondary, label внутри и снаружи, hint/error, disabled/readOnly и очистка по правилам Input.
- Список на Popover с порталом, сменой стороны, шириной поля и прокруткой только вариантов.
- Импорт `@koslibs/components/Select`, типы, ref, отправка id в формах и сброс неуправляемого значения.
- Docs, Playground и примеры множественного выбора и длинного списка.
- Выбранные строки с фоном #E0DBCE; поиск и hover с фоном #F5F3EC.
- Плавное перемещение внутреннего label по аналогии с Input и поворот chevron за 180 мс.
- Тонкий крестик очистки 14×14 px с постоянным label «close».
- Состояния оформления задаются условными CSS-классами через classnames.
- Упрощены обработчики и передача состояния; логика выбора, поиска, навигации и формы собрана в одном хуке.
